# Review Sprint

A static GitHub Pages app for turning product-page details and a real customer experience into a copy-ready Amazon review draft.

## Publish with GitHub Pages

1. Put these files in a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save. GitHub will show the public site address in a minute or two.

## Link imports

Amazon deliberately prevents most browser-only sites from reading its pages. The app first tries a public text-reader fallback for an Amazon link, but the dependable workflow is to copy the product page (Ctrl+A, Ctrl+C) and paste it into the app. No submitted product text or answers are stored by this site.
